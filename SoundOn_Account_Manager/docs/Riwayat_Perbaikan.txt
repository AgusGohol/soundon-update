3.18.0: Tombol Unggah langsung di tiap akun.
- Di tabel akun ada tombol Unggah: pilih file lagu (boleh banyak sekaligus), lagu langsung masuk antrean akun itu dan diunggah otomatis satu per satu. Tidak perlu membuat folder atau mengisi data per lagu.
- Judul diambil dari nama file ("01 - Judul_Lagu.wav" menjadi "Judul Lagu"); artis dari daftar artis akun (dipilih bila lebih dari satu, diingat untuk berikutnya); cover AI SoundOn; lirik otomatis dari file .txt bernama sama bila ada.
- Pengaturan unggah (sekali untuk semua akun, ditanyakan pada unggahan pertama; ubah di Studio > Lainnya > Pengaturan unggah): genre (bawaan Pop), bahasa judul & lirik (English), jenis lagu (ada vokal), eksplisit, tanggal rilis (+7 hari), penulis/penyanyi/produser = nama artis, dan Submit otomatis.
- Juga tersedia di menu ⋯ akun: "Unggah lagu ke akun ini".
- Kolom Diperbarui disembunyikan otomatis pada layar sempit agar tombol tidak terpotong.


3.18.1: Pilihan Eksplisit di SoundOn berbahasa Indonesia dikenali.
- Non-Explicit kini cocok dengan "Noneksplisit", Explicit dengan "Eksplisit", Clean dengan "Bersih".
- Peran kredit juga dikenali dalam bahasa Indonesia (Vocalist = Vokalis, Producer = Produser), termasuk saat memeriksa kredit yang sudah tersimpan.


3.18.2: Monetisasi (Commercial Music Licensing & CapCut) kini diaktifkan, tidak dimatikan.
- Bawaan baru: CML dan CapCut On untuk tombol Unggah dan folder pantau. Bisa dimatikan di Pengaturan unggah ("Monetisasi aktif").
- Lagu dari tombol Unggah yang masih di antrean dan belum terkirim ikut memakai pilihan monetisasi terbaru.
- YouTube Content ID (Add-on berbayar) tetap tidak diaktifkan otomatis.
- Bila SoundOn membuka dialog setelah switch monetisasi dinyalakan, bot berhenti dan menampilkan isi dialog agar bisa dipetakan.


3.18.3: Unggah otomatis tidak macet lagi tanpa batas.
- Pengaman macet: bila proses unggah tidak bergerak selama 4 menit (halaman SoundOn atau Chrome tidak merespons), lagu itu ditandai "Perlu tindakan" dengan keterangan "Macet", lalu antrean lanjut ke lagu berikutnya. Draf tetap terbuka di browser untuk diperiksa.
- Tombol Hentikan kini selalu berhasil: bila Chrome tidak merespons dalam 20 detik, proses dilepas sehingga Studio bisa dipakai dan ditutup lagi.
- Proses yang sudah dilepas tidak bisa lagi mengubah antrean atau ikut berjalan saat lagu berikutnya diproses. Catatan "Submit ditekan" tetap selalu tersimpan agar tidak ada rilis ganda.
- Tab Chrome yang dipakai bot ditampilkan ke depan, dan Chrome akun dibuka tanpa perlambatan tab latar/jendela tertutup, sehingga klik dan unggahan tidak tertahan saat Chrome diminimalkan. (Berlaku setelah Chrome akun ditutup lalu dibuka lagi.)
