SOUNDON ACCOUNT MANAGER v3.5 — PEMILIK & PENGHASILAN ARTIS

PEMASANGAN
1. Tutup aplikasi lama. Ekstrak ZIP ini ke folder baru.
2. Salin soundon.license milik Anda dari folder aplikasi lama ke folder final baru.
3. Jalankan run_app.bat. Gunakan Python dan dependensi yang sama dengan aplikasi lama.
4. Data lama tetap dibaca dari %USERPROFILE%\SoundOnAccounts\accounts.json.
   Sebelum menyimpan perubahan artis, aplikasi membuat salinan .bak dari accounts.json.
   Simpan juga cadangan melalui Pengaturan > Cadangkan data akun sebelum pembaruan.

CARA PAKAI
1. Buka Daftar Akun dan pilih bulan serta tahun penghasilan.
2. Klik Atur Pemilik & Penghasilan pada kartu akun.
3. Klik Tambah Artis, isi nama artis, pemilik (misalnya Pak Mirwan), dan nominal.
4. Isi 5000000 atau 5.000.000 untuk lima juta rupiah, lalu klik Simpan.
5. Pilih artis pada tabel untuk mengubah pemilik atau penghasilan bulan terpilih.
6. Ganti bulan di jendela editor untuk mengisi bulan lain. Klik Simpan setiap selesai mengisi.
7. Hapus Bulan hanya menghapus nominal bulan terpilih. Hapus Artis menghapus artis dan semua riwayatnya; keduanya meminta konfirmasi.

CATATAN
- Penghasilan diisi manual dalam rupiah bulat; belum ditarik otomatis dari SoundOn.
- Nama akun dan nama artis adalah data terpisah. Satu akun dapat menampung beberapa artis.
- Kolom Jumlah Artis lama tetap merupakan angka katalog manual; daftar rincian artis tidak otomatis mengubah angka tersebut.
- Pemilik adalah pemilik saat ini, berlaku untuk semua bulan. Riwayat pergantian pemilik belum dicatat.
- Belum diisi berbeda dengan Rp0. Total menjumlahkan nominal yang sudah diisi.
- Data artis ikut dalam cadangan JSON dan paket transfer akun yang sudah ada.
- File ini merupakan pembaruan source aplikasi Python, bukan EXE mandiri.
